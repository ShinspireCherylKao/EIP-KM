## 六、資源類別管理

對應選單：類別設定

### 6.1 文章分類管理

> 管理前台 KM 文章編輯器的「文章分類」下拉選項。

#### 功能說明
- 後台管理員可**新增、編輯、刪除、排序**文章分類
- 前台 `km-editor.html` 的「文章分類」下拉選單，選項**由此處維護**，不寫死於前端
- 刪除分類時，若該分類下已有文章，須**提示確認**並選擇處理方式（移轉至其他分類 / 標記為「未分類」）

#### 欄位定義

| 欄位 | 必填 | 說明 |
|------|------|------|
| 分類名稱 | ✅ | 最多 **10 字**，不可重複 |
| 分類代碼 | ✅ | 英數字，作為系統識別用 key（如 `sop`、`tech`） |
| 排序序號 | 否 | 數字越小越前面，預設為新增順序 |
| 啟用狀態 | ✅ | 啟用 / 停用；停用後前台不顯示，但不影響已使用該分類的文章 |

#### 預設分類（系統初始資料）

| 分類代碼 | 分類名稱 |
|---------|---------|
| `announcement` | 公告通知 |
| `regulation` | 規範辦法 |
| `sop` | SOP 流程 |
| `tech` | 技術文件 |
| `training` | 教育訓練 |
| `project` | 專案相關 |
| `other` | 其他 |

#### 操作規則
- 分類層級：**單層**（不支援多層巢狀）
- 「其他」為系統保留分類，**不可刪除**，可改名
- 排序方式：後台可拖曳排序或輸入序號，前台下拉選單依此順序顯示

## 八、組織圖

對應選單：組織圖設定

### 8.1 組織圖設定

> 管理公司組織架構，同時作為前台多處部門選單的**唯一資料來源**。

#### 連動範圍
- 前台 KM 文章編輯器（`km-editor.html`）的「所屬部門」下拉選單
- 前台組織圖頁面（`org-chart.html`）
- 前台「我的組織」頁面（`km-my-org.html`）

#### 欄位定義

| 欄位 | 必填 | 說明 |
|------|------|------|
| 部門名稱 | ✅ | 最多 **20 字**，不可重複 |
| 部門代碼 | ✅ | 英數字，作為系統識別用 key（如 `HR`、`BU1`） |
| 上級部門 | 否 | 選擇父層部門，空值表示最上層 |
| 部門主管 | 否 | 指定部門主管（用於審核流程） |
| 排序序號 | 否 | 同層級內的顯示順序 |
| 啟用狀態 | ✅ | 啟用 / 停用；停用後前台不顯示於下拉選單，但不影響已發佈文章的歸屬 |

#### 操作規則
- 支援**多層樹狀結構**
- 刪除部門時，若該部門下已有文章或子部門，須**提示確認**並選擇處理方式
- 新增 / 修改部門後，前台所有引用部門清單的頁面**即時生效**（無需手動同步）

### 10.5 外部連結管理

#### 功能說明
- 後台提供外部分享連結的統一管理介面，供管理員查看、搜尋及停用所有已產生的外部連結。

#### 列表顯示欄位
- 連結 URL
- 分享的檔案名稱
- 分享者（建立者）
- 建立時間
- 到期時間
- 連結狀態（生效中 / 已停用 / 已過期）

#### 搜尋與篩選
- 支援依「**連結狀態**」篩選：
  - **全部**：顯示所有連結
  - **生效中**：僅顯示當前有效且未停用的連結
  - **已停用**：僅顯示被手動停用的連結
  - **已過期**：僅顯示已超過有效期限的連結
- 支援依檔案名稱、分享者名稱進行關鍵字搜尋。
- 支援依建立時間、到期時間進行日期範圍篩選。

#### 管理操作
- **停用連結**：管理員可強制停用任一生效中的外部連結，停用後外部人員無法存取。
- **重新啟用**：可針對已停用但尚未過期的連結重新啟用。
- **已過期連結不可重新啟用**，需由前台使用者重新產生新連結。
