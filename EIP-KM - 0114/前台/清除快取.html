🔄 清除瀏覽器快取

⚠️ 為什麼需要清除快取？

您修改了 km-script.js 檔案，但瀏覽器仍在使用舊版本。這導致 AI 功能無法正確識別您的管理員權限。

✅ 方法一：強制重新載入（推薦）

1. 開啟前台頁面 (index.html)

2. 按下快速鍵：

Ctrl + Shift + R
或
Ctrl + F5

3. 等待頁面完全重新載入

✅ 方法二：開發者工具清除快取

1. 開啟前台頁面

2. 按 F12 開啟開發者工具

3. 切換到「Network」(網路) 分頁

4. 勾選「Disable cache」(停用快取)

5. 重新整理頁面 F5

✅ 方法三：完整清除網站資料

1. 開啟前台頁面

2. 按 F12 開啟開發者工具

3. 切換到「Application」(應用程式) 分頁

4. 點選左側「Storage」→「Clear site data」

5. 點擊「Clear site data」按鈕

6. 重新整理頁面

🧪 方法四：使用下方按鈕自動清除（實驗性）

✅ 成功！

📋 清除後的驗證步驟：

  1. 開啟前台頁面
  2. 進入「AI 加值」功能
  3. 點選「智慧搜尋與問答」
  4. 輸入：「B專案內容為?」
  5. 應該可以看到 B 專案的相關文件，而不是權限錯誤
🚀 返回前台頁面
